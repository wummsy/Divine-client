# 🎮 Controls & Keybinds

Divine Client provides modern, customizable controls and hotkeys for in-game HUDs, mod toggles, and builder utilities.

---

## ⌨️ Default Keybindings

| Keybind | Function | Category |
| :--- | :--- | :--- |
| <kbd>Right Shift</kbd> | Open Divine Client Mod Configuration Menu | Divine Client UI |
| <kbd>C</kbd> | Smooth OptiFine-Style Camera Zoom | Camera & View |
| <kbd>F6</kbd> | Toggle Divine Freelook (360° Perspective) | Camera & View |
| <kbd>F7</kbd> | Open Wardrobe & Cosmetics Selector | Cosmetics |
| <kbd>F8</kbd> | Toggle HUD Overlays Visibility (CPS, Keystrokes, Armor) | HUD System |
| <kbd>Alt</kbd> + <kbd>B</kbd> | Open Builder Studio / Axiom Editor Bar | Builder Studio |
| <kbd>F3</kbd> + <kbd>D</kbd> | Clear Chat / Debug Logs | Debug & Logs |

---

## 🛠️ Customizing Keybinds

You can customize all keybindings at any time:
1. Press <kbd>Esc</kbd> in-game and navigate to **Options** > **Controls** > **Key Binds**.
2. Scroll down to the **Divine Client** and **Builder Studio** sections.
3. Click any action to assign a new hotkey.
