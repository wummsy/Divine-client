DIVINE CLIENT

Privacy Policy

Effective Date: September 2026 • Transparent, local-first privacy practices.

1. Local-First Architecture
Divine Client is architected around a strict Local-First principle. All instance data, game files, mods, texture packs, shaders, screenshots, local world saves, server properties, crash logs, and custom JVM parameters are stored locally on your own machine. Divine Client does not upload or mirror your personal Minecraft files to remote servers.
2. Hardware Device Code & Abuse Prevention
To maintain network security and enforce hardware-level bans against abusive actors, Divine Client computes a salted, deterministic hardware hash (DEV-XXXX-XXXX-XXXX-XXXX) derived from system identifiers. This code is used exclusively for platform integrity, rate limiting, and ban enforcement. It cannot be used to inspect your private personal documents or extract personally identifiable files.
3. Account Authentication & Credentials
Microsoft & Xbox Authentication: When signing into Minecraft via Microsoft, authentication occurs directly with official Microsoft OAuth servers (microsoft.com/link). Divine Client never receives, logs, or transmits your Microsoft password. Refresh tokens are stored encrypted in your local operating system keyring/storage.

Offline Accounts: Offline player profiles and UUIDs are generated and stored strictly on your local disk.
4. Discord Integration & Rich Presence
Connecting your Discord account via the Divine Client Gateway or Discord link dialog is optional. Divine Client requests only basic identity information (identify scope: Discord user ID, username, and avatar URL) to display your profile in the launcher and synchronize mutual friends. When enabled, Discord Rich Presence broadcasts only the game title (Divine Client) and current active instance name to your Discord profile.
5. Dedicated Servers & Player Network
When hosting local Paper or Fabric servers or participating in the in-app player network, your chosen server IP and port are shared only with players you explicitly invite or whitelist. Collaborator permissions granted via Discord username allow team management of server instances without exposing underlying host machine access.
6. Zero Behavioral Telemetry & No Data Selling
Divine Client does not sell, rent, or monetize your data. We do not track in-game behavior, keystrokes, location coordinates, or advertising IDs. Searches for mods, resource packs, shaders, and plugins communicate directly with the Modrinth and CurseForge public APIs.
