Privacy Policy

Transparent, local-first data architecture. Divine Client does not track your gameplay, sell your data, or collect behavioral telemetry.

1. Local-First Architecture
All Minecraft versions, mod configurations, worlds, screenshots, server databases, and game saves are stored directly on your local computer. Divine Client never uploads your game files or world data to remote servers.
2. Discord Authentication & Profile Data
When connecting your Discord account, we only request public identification data (Discord User ID, Global Display Name, and Avatar URL) through standard OAuth2 scopes. We never access your private messages, email address, passwords, or server membership lists.
3. Zero Third-Party Advertising
Divine Client contains zero commercial tracking SDKs, no behavioral telemetry trackers, and no third-party advertisements.
4. Multiplayer & Server Tunnel Relays
When hosting dedicated multiplayer servers using automated relay connections, game network traffic is forwarded directly to connected players with zero content inspection or logging of game events.
