## What is Divine Client?

Divine Client is a lightweight Minecraft launcher and custom Fabric mod suite designed to give you an out-of-the-box competitive edge without clutter. It pairs sub-second launch speeds and automated Java runtime self-healing with an integrated Divine in-game HUD, custom 2D main menu, creator builder tools, and built-in server hosting.

---

## Key Features

### ⚔️ In-Game Mod & PvP Suite
Access everything instantly in-game by pressing **`Right Shift`** or **`M`**:
- **Dynamic Keystrokes & CPS Counter**: Real-time WASD and click-rate tracking with a sliding window buffer.
- **Armor & Equipment Status**: Live durability health bars and percentage counters.
- **Potion Effect Timers**: Active status effects with remaining duration timers.
- **Cinematic Smooth Zoom (`C`)**: Fluid camera zoom without needing third-party mods.
- **Toggle Sprint & Fullbright (`G`)**: Built-in sprint locking and clean gamma boost.
- **FPS & Coordinate HUD**: Real-time FPS metrics and XYZ coordinates with Nether conversion.

### 🏛️ Builder Preset (1.21.11 Fabric)
Ready for mega-builds and cinematic recording right on install:
- **Axiom** &mdash; Next-gen real-time voxel sculpting, painting, and terraforming.
- **WorldEdit** &mdash; The industry-standard in-game world editing tool.
- **Flashback** &mdash; High-performance cinematic camera pathing and replay recording.
- **Fabric API & Sodium Ready** &mdash; Maximum render performance and chunk loading.

### ⚡ Sub-Second Desktop Launcher
- **Instant Launch Pipeline**: Intelligent version caching boots the game in under 2 seconds.
- **1-Click Java Fix**: Built-in OpenJDK 21 LTS repair tool resolves missing `jli.dll` and `jvm.dll` system errors automatically.
- **Live Output Console**: Watch game logs stream in real time with auto-scroll and quick copy tools.
- **Dual Dashboard Modes**: Dedicated obsidian **Divine Mode** for instant 1.21.11 play, alongside a carousel **Instances Mode** for custom modpacks.

### 🌐 Discord Sync & Server Fleet
- **1-Click Discord Linking**: Link your Discord account via the `/link?code=XXXX` web portal to sync friends and cloaks.
- **DivineBot Integration**: Control your client, check player hardware codes, and sync in-game friend lists directly from Discord.
- **Integrated Server Hosting**: Spin up and host Paper or Fabric servers for your friends in seconds with automated tunnel routing.

## Default Controls & Keybindings

| Key | Action |
| :--- | :--- |
| **`Right Shift`** or **`M`** | Open Divine In-Game Mod Menu & Settings |
| **`C`** | Smooth Camera Zoom |
| **`G`** | Toggle Fullbright / Gamma Boost |
| **`R`** | Toggle Sprint Mode |
| **`W` `A` `S` `D` + `LMB` `RMB`** | Keystrokes HUD with real-time CPS counter |
