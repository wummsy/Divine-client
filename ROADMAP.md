# Divine Client &mdash; Development Roadmap & Vision

This roadmap outlines the planned development milestones, feature expansions, and architectural improvements for **Divine Client** and the **Divine Mod Suite**.

---

## 🎯 Current Milestone: v5.0.0 (Unified Instance Launching & Collaborator Permissions)
- [x] High-performance launcher engine with robust instance launching across Vanilla, Fabric, Forge, and Quilt.
- [x] Automated Java 21 LTS runtime health check & missing DLL auto-repair.
- [x] Granular Collaborator Access System for dedicated servers with Discord bot commands.
- [x] Integrated client mod suite with custom Divine-style 2D title screen.
- [x] In-game HUD suite: FPS, Coordinates, Keystrokes, Sprint Toggle, Fullbright, Zoom.
- [x] Discord OAuth2 web portal (`/link?code=XXXX`) and DivineBot synchronization.
- [x] Hardware device ID moderation engine (`/ban`, `/unban`, `/lookup`).

---

## 🚀 Upcoming Milestone: v4.1.0 (Advanced In-Game HUD & Combat Suite)
- [ ] **Dynamic CPS Monitor** &mdash; 1-second sliding window ring buffer for Left/Right click rate with customizable display positions.
- [ ] **Armor & Hand Durability HUD** &mdash; Live equipment health bars with percentage and low-durability warning tints.
- [ ] **Potion Effect Status HUD** &mdash; Real-time status indicators showing potion names, amplifier levels, and countdown timers.
- [ ] **Combo & Hit Tracker** &mdash; Dynamic counter displaying active consecutive hits landed in PvP encounters.
- [ ] **Crosshair Studio** &mdash; Modular in-game crosshair designer supporting custom outlines, dot centers, adaptive dynamic spread, and color themes.
- [ ] **Hypixel Minigame Utilities** &mdash; Auto-GG, Auto-Tip, Bedwars/Skywars stat overlays, and quickplay selector radial wheel.

---

## 🎨 Milestone: v4.2.0 (Custom Cosmetics & In-Game 3D Renderer)
- [ ] **Real-Time Cosmetic Sync** &mdash; Native client-side rendering for animated celestial cloaks, wings, bandanas, and pet companions.
- [ ] **Creator Wardrobe Studio** &mdash; In-game color picker, emissive glow slider, and previewer for claimed cosmetics.
- [ ] **Gift Code Generation System** &mdash; Web dashboard and Discord bot commands for server owners to generate single-use and multi-use redeem codes.
- [ ] **Custom Capes Pipeline** &mdash; Support for custom HD capes, Minecraft capes, and Divine animated cloaks with physics simulation.

---

## 🛠️ Milestone: v4.3.0 (Builder Studio & Replay Enhancements)
- [ ] **Axiom & WorldEdit Fast-Switch** &mdash; Contextual builder radial menu for rapid brush size, mask, and clipboard manipulation.
- [ ] **Integrated Flashback Replay Viewer** &mdash; Native launcher-integrated replay browser with 1-click timeline scrubbing and mp4 export.
- [ ] **Schematic Cloud Vault** &mdash; Cloud backup and 1-click sharing of `.schem` / `.litematic` files between team members.
- [ ] **Camera Path Keyframe Visualizer** &mdash; 3D path spline rendering for cinematic camera flythroughs.

---

## 🌐 Milestone: v4.4.0 (Dedicated Server Fleet & Cloud Sync)
- [ ] **Multi-Region Tunnel Mesh** &mdash; Low-latency Playit / bore routing with automatic closest-region fallback (NA-East, EU-Central, AP-East).
- [ ] **Cross-Platform Settings Cloud Backup** &mdash; Sync launcher settings, keybinds, and mod configurations across multiple PCs via linked Discord account.
- [ ] **In-Game Server Manager HUD** &mdash; Start, restart, stop, and monitor dedicated Paper/Fabric server instances directly from inside Minecraft.

---

## 🔒 Milestone: v4.5.0 (Divine Shield & Competitive Integrity)
- [ ] **Divine Shield Anti-Cheat Engine** &mdash; Client-side integrity verification ensuring fair play on partnered competitive servers.
- [ ] **Screenshot & Replay Watermarking** &mdash; Cryptographically signed replay tokens for tournament match submissions.
- [ ] **Automated Crash Diagnostics & Telemetry** &mdash; 1-click crash log analyzer providing instant fix suggestions for conflicting mods.
